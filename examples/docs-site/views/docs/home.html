HTML primeiro

Templates resolvidos 100% no servidor. A primeira resposta já é conteúdo utilizável — sem tela vazia esperando JavaScript.

JavaScript sob demanda

Um runtime pequeno, carregado só em páginas que usam diretivas. Formulários continuam funcionando sem ele.

Seguro por padrão

Escape contextual automático, linguagem de expressão restrita sem eval, CSRF integrado e CSP estrita.

Servidor é a autoridade

Permissões, validações e regras de negócio ficam no servidor. O cliente só apresenta resultados e estado transitório.

app.js 
import express from 'express';
import { createFlash } from 'flash';
import { expressAdapter } from 'flash/express';

const flash = createFlash({
  views: './src/views',
  components: './src/components'
});

flash.get('/clients', async (ctx) => {
  const clients = await clientService.list({ search: ctx.query.q });

  return ctx.render('clients/index', {
    title: 'Clientes',
    clients
  });
});

app.use(expressAdapter(flash));
